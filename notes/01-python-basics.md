# 01. Python Basics

## Core ideas
- Python is a beginner-friendly, high-level language.
- Code runs in order unless conditions or loops change the flow.
- Variables store data.
- Values have types.

## Data types
- `int` -> whole numbers
- `float` -> decimal numbers
- `str` -> text
- `bool` -> `True` / `False`
- `list`, `tuple`, `set`, `dict` -> collections

## Operators
- Arithmetic: `+`, `-`, `*`, `/`, `%`, `**`
- Comparison: `==`, `!=`, `>`, `<`, `>=`, `<=`
- Logical: `and`, `or`, `not`
- Assignment: `=`, `+=`, `-=`, `*=`

## Input and output
- `print()` shows output.
- `input()` reads user input.
- Input is a string by default.
- Convert when needed: `int(input())`, `float(input())`

## Conditions
- `if`, `elif`, `else`
- Conditions decide which block runs.

## Loops
- `for` loops iterate over items.
- `while` loops continue while a condition is true.
- `break` exits a loop.
- `continue` skips to next iteration.

## Quick recall
- Variables store data.
- Python uses dynamic typing.
- Operators help with calculations and logic.
- Conditionals control decisions.
- Loops repeat tasks.
