# 02. Data Structures

## Lists
- Ordered and changeable.
- Allows duplicate values.
- Common actions: append, remove, sort, index, slice.

## Tuples
- Ordered and immutable.
- Good for fixed data.

## Sets
- Unordered.
- Stores unique values.
- Great for membership checks and removing duplicates.

## Dictionaries
- Key-value pairs.
- Good for lookup and structured data.
- Example: `{ "name": "Alice", "age": 25 }`

## Indexing and slicing
- Access items by position.
- Example: `text[0]`, `numbers[1:4]`

## Comprehensions
- Compact way to create collections.
- Example: `[x * 2 for x in range(5)]`

## Nested data
- Lists or dictionaries can contain other collections.
- Useful for structured, real-world information.

## Choosing a structure
- List -> ordered data
- Set -> unique values
- Dictionary -> key-based lookup
- Tuple -> fixed data

## Quick recall
- Lists are flexible.
- Tuples are fixed.
- Sets remove duplicates.
- Dictionaries organize key-value data.
- Comprehensions make code shorter.
