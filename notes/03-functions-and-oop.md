# 03. Functions and OOP

## Functions
- Functions are reusable blocks of code.
- Defined with `def`.
- Can accept parameters.
- Can return values.

## Function ideas
- Positional arguments
- Keyword arguments
- Default parameters
- Return statements
- Reusing logic

## Modules
- Python files can be imported as modules.
- Helps organize code.
- Reuse logic across scripts.

## Classes and objects
- A class is a blueprint.
- An object is an instance of a class.
- Attributes store data.
- Methods define behavior.

## Constructor
- `__init__` sets up the object.
- Used to initialize attributes.

## OOP concepts
- Encapsulation -> data and methods together
- Inheritance -> child classes reuse parent behavior
- Composition -> building objects from smaller objects

## Dataclasses
- Cleaner way to define simple classes.
- Use `@dataclass`.
- Good for structured data.

## Text processing examples
- `strip()` removes leading/trailing spaces.
- `split()` breaks text into words.
- `join()` combines pieces.
- `lower()` makes text lowercase.
- `len()` counts characters.

## Composition pattern
- Small helper objects can work together.
- Example: cleaner + keyword finder + counter + analyzer.
- This makes code modular and easier to maintain.

## Quick recall
- Functions reduce repetition.
- Classes organize related behavior.
- Objects are created from classes.
- Composition builds bigger workflows from smaller parts.
- Text processing is often done in steps.
